Pusat Cadangan & Pemulihan Data

Kenapa ini Penting?

Aplikasi ini menyimpan semua data keuangan **secara langsung di HP atau laptop Anda** (menggunakan memori browser, bukan internet). Jika Anda membersihkan riwayat browser atau HP mengalami kerusakan, data Anda bisa hilang. Lakukan **Cadangkan Data** secara rutin setelah mencatat utang agar pembukuan Anda selalu aman!

Unduh Data Pembukuan (Ekspor)

Download semua data nasabah, alamat, dan seluruh riwayat transaksi ke dalam file cadangan JSON atau tabel Microsoft Excel (CSV).

Pulihkan Data Pembukuan (Impor JSON)

Pilih file cadangan `.json` yang pernah Anda unduh sebelumnya untuk memulihkan seluruh data transaksi dan daftar nasabah kembali ke perangkat ini.

Format file harus berupa .json yang valid

Impor Saldo Awal / Utang Lama dari Excel / CSV

Pindahkan catatan utang lama di buku fisik Mama secara cepat! Unduh dulu file contoh Excel/CSV, isi nama nasabah & saldo utangnya di laptop/HP, lalu unggah ke sini.

Sinkronisasi Cloud Real-Time (HP Mama & HP Anda) ☁️

Menghubungkan pembukuan antara HP Mama dan HP/Laptop Anda secara otomatis dari jarak jauh! Cukup masukkan **Kode Sync** yang sama di kedua perangkat.
